# Design Context – dFFA-Rechner

## Target Audience
- Primary: Active firefighters (18–60+) and youth firefighters (10–17) in German fire departments
- Secondary: Training officers and competition coordinators running group assessments
- Device context: Mostly desktop (official use at fire station), but also mobile (self-check at home)

## Use Cases
1. Look up dFFA/dJFFA badge requirements by age group and discipline
2. Calculate own badge level from individual performance values
3. Record group performance at official badge assessments (CSV import/export)
4. Understand discipline rules via info tooltips

## Brand Personality / Tone
- **Official but accessible**: This is a utility for the fire service — authoritative, precise, practical
- **No-nonsense**: Feuerwehr aesthetics, not sports app aesthetics. Function first.
- **Trustworthy**: Data must feel accurate. Clean tables, legible numbers.
- **Proud**: Firefighter identity is strong. The badge matters. Results should feel earned.

## Design System
- **Primary accent**: `--fire-red: #DC2626` (Feuerwehr-Rot) — used sparingly for CTAs, active states, headings
- **Neutrals**: Gray scale `--gray-50` to `--gray-900` — currently pure gray, candidate for warm (red-tinted) toning
- **Display font**: Bebas Neue (H1 only) — bold, heroic, Feuerwehr-appropriate
- **Body font**: Work Sans — clean, highly legible at small sizes
- **Badge colors**: `--bronze: #CD7F32`, `--silver: #C0C0C0`, `--gold: #FFD700`
- **Feedback**: `--success: #10B981`, `--error: #EF4444`, `--warning: #F59E0B`

## Accessibility Requirements
- WCAG 2.1 AA minimum (public utility tool for all ages and abilities)
- Touch targets ≥ 44×44px (used on mobile)
- Color contrast ≥ 4.5:1 for all text
- Full keyboard navigation, skip links, focus traps in modals

## Tech Constraints
- Vanilla HTML/CSS/JS — no framework, no build step
- Deployed as static site on GitHub Pages
- Must work offline after first load (no API dependencies)
- Data: Two separate JS data files (`dffa-data.js`, `djffa-data.js`)
